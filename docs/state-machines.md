# State machines

This maps the 39 machines inventoried before the state refactor. Runtime callers use the owners below. Some machines were already explicit on the integration baseline (`3448957`); their existing state and reducers are retained. The IDs describe responsibilities, so graph traversal, witness selection, and caching span several owners.

State stays in its domain module. Immutable reducers return the next state. Collectors construct and evolve privately owned collections within one operation. Resource owners manage publication and restoration. There is no shared transition framework.

For M31, each witness search costs O(V + E + L) for callable vertices V, call edges E, and rendered witness length L. Searches run separately for F qualifying call sites, so the overall bound is O(F(V + E) + L_total); the layered pure-branch case has a constant number of qualifying sites. These bounds assume constant-time hashing.
