# Rules and built-in rulesets

Rule names are stable public identities. Priorities run from 1 (highest) to 5 (lowest). A threshold comparison is described by each finding message; property values below are catalogue defaults. `python` overrides `LongVariable.maximum` to `35`.

| Component | Rule | Priority | Default properties | Behavior, trigger, applicability, and Python differences |
|---|---|---:|---|---|
| `naming` | `ShortClassName` | 3 | `minimum=3` | Reports non-exempt class names shorter than `minimum`. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `naming` | `LongClassName` | 3 | `maximum=40` | Reports non-exempt class names longer than `maximum`. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `naming` | `ShortVariable` | 3 | `minimum=3` | Reports non-exempt parameter/property/variable names shorter than `minimum`. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `naming` | `LongVariable` | 3 | `maximum=20` | Reports non-exempt parameter/property/variable names longer than `maximum`. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `naming` | `ShortMethodName` | 3 | `minimum=3` | Reports non-exempt function/method names shorter than `minimum`. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `naming` | `ConstantNamingConventions` | 3 | — | Reports statically identified constants that are not `UPPER_CASE`. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `naming` | `BooleanGetMethodName` | 3 | — | Reports proven-boolean methods using a `get` prefix instead of a Python boolean prefix. **Applicable.** Requires an explicit bool annotation or conservative literal-boolean proof; accepts prefixes such as `is_`, `has_`, `can_`, `should_`, `was_`, `will_`, and `did_`. |
| `naming` | `ConstructorWithNameAsEnclosingClass` | 3 | — | Never reports because Python has no separately named constructor declaration. **Not applicable.** Python has no separately named constructor declaration; the rule loads and stays quiet. |
| `codesize` | `CyclomaticComplexity` | 3 | `reportlevel=10` | Reports callables whose Python decision count plus one is greater than or equal to `reportlevel`. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `codesize` | `NPathComplexity` | 3 | `minimum=200` | Reports callables whose syntax-only path count is greater than or equal to `minimum`. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `codesize` | `ExcessiveParameterList` | 3 | `minimum=10` | Reports callables with at least `minimum` parameters; every Python parameter form is counted once. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `codesize` | `ExcessiveMethodLength` | 3 | `minimum=100` | Reports callables with at least `minimum` physical lines. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `codesize` | `ExcessiveClassLength` | 3 | `minimum=1000`, `ignore-whitespace=false` | Reports classes with at least `minimum` lines; `ignore-whitespace=true` counts nonblank lines only. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `codesize` | `ExcessivePublicCount` | 3 | `minimum=45` | Reports classes with at least `minimum` public fields plus concrete methods. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `codesize` | `TooManyFields` | 3 | `maxfields=15` | Reports classes with more than `maxfields` statically declared/assigned fields. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `codesize` | `TooManyMethods` | 3 | `maxmethods=25`, `ignorepattern=(^(set\|get\|is\|has\|with))i` | Reports classes with more than `maxmethods` concrete methods after the regular-expression `ignorepattern` exclusion. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `codesize` | `TooManyPublicMethods` | 3 | `maxmethods=10`, `ignorepattern=(^(set\|get\|is\|has\|with))i` | Reports classes with more than `maxmethods` public concrete methods after `ignorepattern`. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `codesize` | `ExcessiveClassComplexity` | 3 | `maximum=50` | Reports classes whose summed concrete-method cyclomatic complexity is at least `maximum`. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `unusedcode` | `UnusedLocalVariable` | 3 | — | Reports conservative lexical local/comprehension bindings with no proven use. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `unusedcode` | `UnusedFormalParameter` | 3 | — | Reports conservative callable parameters with no proven use. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `unusedcode` | `UnusedPrivateField` | 3 | — | Reports underscore-private fields with no proven class use, subject to framework/dynamic-access safeguards. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `unusedcode` | `UnusedPrivateMethod` | 3 | — | Reports underscore-private methods with no proven class use, subject to framework/dynamic-access safeguards. **Applicable.** Uses direct Python syntax; no dependency import or execution is required. |
| `cleancode` | `BooleanArgumentFlag` | 1 | `exceptions=`, `ignorepattern=` | Reports boolean parameters except comma-separated `exceptions` or names matching `ignorepattern`. **Applicable.** Uses boolean annotations/defaults and configurable exceptions without runtime type resolution. |
| `cleancode` | `ElseExpression` | 1 | — | Reports `else` after an always-terminating preceding branch. **Applicable.** Checks Python else clauses after terminating branches. |
| `cleancode` | `StaticAccess` | 1 | `exceptions=`, `ignorepattern=` | Reports class-like static calls except comma-separated `exceptions` or names matching `ignorepattern`. **Applicable.** Checks conservative class-like static calls with configurable exceptions. |
| `cleancode` | `IfStatementAssignment` | 1 | — | Reports assignment expressions in `if` or `while` conditions. **Applicable.** Checks assignment expressions only in if/while condition contexts. |
| `cleancode` | `DuplicatedArrayKey` | 2 | — | Reports repeated statically equal, hashable dictionary-literal keys. **Applicable.** The family identity checks duplicate statically knowable dictionary-literal keys. |
| `design` | `ExitExpression` | 1 | — | Reports conservative Python process-exit calls, once per lexical scope. **Applicable.** Checks conservative Python exit-call syntax and visible aliases. |
| `design` | `GotoStatement` | 1 | — | Never reports because Python has no goto statement. **Not applicable.** Python has no goto statement; the rule loads and stays quiet. |
| `design` | `CountInLoopExpression` | 2 | — | Reports builtin `len()` calls in `while` conditions. **Applicable.** Checks repeated len() calls in while conditions, not idiomatic for/range constructs. |
| `design` | `DevelopmentCodeFragment` | 2 | `unwanted-functions=`, `markers=TODO,FIXME,HACK` | Always reports `breakpoint` and `pdb.set_trace` calls, plus any additional comma-separated `unwanted-functions`, and case-insensitive comma-separated comment `markers` (default `TODO,FIXME,HACK`). **Applicable.** Always includes `breakpoint` and `pdb.set_trace` even when `unwanted-functions` is empty; markers stay case-insensitive. |
| `design` | `EmptyCatchBlock` | 2 | — | Reports exception handlers containing only `pass` or ellipsis. **Applicable.** Checks pass- and ellipsis-only exception handlers. |
| `design` | `CouplingBetweenObjects` | 2 | `maximum=13` | Reports classes with at least `maximum` deduplicated syntax-only external dependencies. **Applicable.** Counts syntax-only Python imports, bases, decorators, annotations, and external references. |
| `design` | `GlobalVariable` | 1 | `report-immutable=false` | Reports observed mutated module bindings; `report-immutable=true` reports all initialized module bindings, including `Final`. **Applicable.** Checks observed mutable module state; report-immutable broadens the check. |
| `design` | `LackOfCohesionOfMethods` | 3 | `maximum=1` | Reports classes whose Python LCOM4 connected-component value is greater than `maximum`. **Applicable.** Uses LCOM4 connections through instance state and receiver calls with Python protocol/accessor exclusions. |
| `controversial` | `CamelCaseClassName` | 1 | — | Reports non-private class names that are not Python CapWords. **Adapted.** The stable family identity enforces Python CapWords. |
| `controversial` | `CamelCaseMethodName` | 1 | `allow-underscore=false`, `allow-underscore-test=false` | Reports non-private function/method names that are not Python snake_case. **Adapted.** The stable family identity enforces snake_case functions and methods; family underscore-compatibility properties remain loadable and do not disable required snake_case. |
| `controversial` | `CamelCasePropertyName` | 1 | `allow-underscore=false`, `allow-underscore-test=false` | Reports non-private property names that are not Python snake_case. **Adapted.** The stable family identity enforces snake_case properties; family underscore-compatibility properties remain loadable and do not disable required snake_case. |
| `controversial` | `CamelCaseParameterName` | 1 | `allow-underscore=false` | Reports non-private, non-conventional parameter names that are not Python snake_case. **Adapted.** The stable family identity enforces snake_case parameters; family underscore-compatibility properties remain loadable and do not disable required snake_case. Conventional `self`/`cls`, short indexes/coordinates/exceptions, and `*args`/`**kwargs`-style names stay quiet. |
| `controversial` | `CamelCaseVariableName` | 1 | `allow-underscore=false` | Reports non-private, non-constant variable names that are not Python snake_case. **Adapted.** The stable family identity enforces snake_case variables; family underscore-compatibility properties remain loadable and do not disable required snake_case. Keyword trailing underscores and conventional short names stay quiet. |

## Membership

- **naming**: `ShortClassName`, `LongClassName`, `ShortVariable`, `LongVariable`, `ShortMethodName`, `ConstantNamingConventions`, `BooleanGetMethodName`, `ConstructorWithNameAsEnclosingClass`
- **unusedcode**: `UnusedPrivateField`, `UnusedLocalVariable`, `UnusedPrivateMethod`, `UnusedFormalParameter`
- **cleancode**: `BooleanArgumentFlag`, `ElseExpression`, `StaticAccess`, `IfStatementAssignment`, `DuplicatedArrayKey`
- **design**: `ExitExpression`, `GotoStatement`, `CountInLoopExpression`, `DevelopmentCodeFragment`, `EmptyCatchBlock`, `CouplingBetweenObjects`, `GlobalVariable`, `LackOfCohesionOfMethods`
- **python**: `CyclomaticComplexity`, `NPathComplexity`, `ExcessiveMethodLength`, `ExcessiveClassLength`, `ExcessiveParameterList`, `ExcessivePublicCount`, `TooManyFields`, `TooManyMethods`, `TooManyPublicMethods`, `ExcessiveClassComplexity`, `ShortClassName`, `LongClassName`, `LongVariable` (maximum=35), `ShortMethodName`, `ConstantNamingConventions`, `BooleanGetMethodName`, `UnusedPrivateField`, `UnusedLocalVariable`, `UnusedPrivateMethod`, `IfStatementAssignment`, `DuplicatedArrayKey`, `DevelopmentCodeFragment`, `EmptyCatchBlock`, `CouplingBetweenObjects`, `GlobalVariable`, `LackOfCohesionOfMethods`, `CamelCaseClassName`, `CamelCaseMethodName`, `CamelCasePropertyName`, `CamelCaseParameterName`, `CamelCaseVariableName`
- **controversial**: `CamelCaseClassName`, `CamelCaseMethodName`, `CamelCasePropertyName`, `CamelCaseParameterName`, `CamelCaseVariableName`
- **opinionated**: `ShortVariable`, `UnusedFormalParameter`, `BooleanArgumentFlag`, `ElseExpression`, `StaticAccess`, `CountInLoopExpression`, `ExitExpression`
- **codesize**: `CyclomaticComplexity`, `NPathComplexity`, `ExcessiveMethodLength`, `ExcessiveClassLength`, `ExcessiveParameterList`, `ExcessivePublicCount`, `TooManyFields`, `TooManyMethods`, `TooManyPublicMethods`, `ExcessiveClassComplexity`

Leading-underscore private names, dunder names, conventional receivers and short index/coordinate/exception names are handled conservatively. Constants and type-parameter declarations retain their Python roles. Computed names are not guessed.
