# Source analysis fuzzing

Run a bounded source analysis fuzz campaign. On Linux, use:

```sh
uv run --python 3.11 --extra fuzz python fuzz/fuzz_source_file.py -runs=1000 fuzz/corpus/source-analysis
```

On macOS, Atheris builds from source. After `brew install llvm`, use:

```sh
CLANG_BIN="$(brew --prefix llvm)/bin/clang" uv run --python 3.11 --extra fuzz python fuzz/fuzz_source_file.py -runs=1000 fuzz/corpus/source-analysis
```

The target writes generated bytes to one temporary `source.py` file. It sends
that file through the MessPy `text` and `codesize` command behavior. Clean,
finding, and processing-error exit statuses are normal target results.

The supplied corpus seeds clean source, an `ExcessiveMethodLength` finding,
malformed source, and non-UTF-8 source. Atheris may add coverage-guided inputs
to that corpus directory.

An unexpected MessPy exception stops Atheris. Atheris writes its crashing input
to a `crash-*` file in the working directory. Reproduce it with the same
command and replace `-runs=1000` with `crash-<input>`.

```sh
uv run --python 3.11 --extra fuzz python fuzz/fuzz_source_file.py crash-<input>
```
