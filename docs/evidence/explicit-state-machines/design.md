# Chosen design

Use candidate A's local state owners as the base. Both candidates converge on authoritative state in the owning module and retaining adequate existing immutable interpreters and library caches. Candidate B contributes typed deferred provenance variants, continuation records for traversal context, and resource ownership instead of decorative publication phases.

Runtime callers use each owner or named reducer. Do not create a generic state-machine framework. Existing _BindState, _NamingState, _State, _Flow, _Context, Storage and cache decorators can remain when their existing transitions actually own the invariant. Raw tuple stacks, multi-variable cursors, sentinel conventions, proof latches and fixed-point locals receive concrete domain representations. Domain transition functions may remain free functions when they take and return the state explicitly. No class is required merely to rename a local accumulator.

Synthesis rubric. Both candidates pass preservation of traversal order, identity, precedence provenance, runtime ownership, local interfaces, and behavioral verification. A keeps mutability local where copying queues would add cost. B's fully immutable alternative has no correctness advantage for privately owned traversal stacks. No additional global dispatcher is introduced. The completed external Gemini4 design assessment confirmed the local-owner approach and identified ordering and provenance boundaries to preserve. Its suggestion to freeze all collectors was declined where it would introduce repeated collection copies; locally constructed collectors preserve linear accumulation. Native configured Claude/Grok design models are unavailable in this harness, so both native candidates inherited the parent; external Gemini4 provides the independent model family.

Implementation partitions. Dataflow owns ownership.py, execution.py, effects.py, captures.py and reachability.py. Bindings owns callables.py, names.py, syntax.py, callgraph.py, constants.py, cohesion.py, onion.py and protocols.py. The analyzer worker owns analyzer.py in a fourth isolated worktree. Root owns cli.py, rulesets.py, verification scripts, docs and evidence. Workers have separate worktrees. Root integrates only verified commits and owns the canonical trail.

Baseline. Existing suite ran466 tests with two skips and one timing failure while other checks ran concurrently. The failure is an existing two-second wall-clock assertion at test_explicitness_ownership.py:410. The isolated rerun passed in 0.996s (baseline-timing-rerun.log); the final integrated suite also passes the unchanged assertion. The initial differential checker matched current main on487 source samples and13 CLI cases. Self-analysis passed before source changes.
